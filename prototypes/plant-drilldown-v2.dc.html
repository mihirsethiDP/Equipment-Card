Card profiles by equipment type

Same four levels · the equipment card composes itself from its type

Plant → unit process → unit → equipment is unchanged. At equipment level the card reads a profile for its type: an ordered list of anchor blocks and the tabs that apply. A blower is a rotating machine, so it leads with attributes and a health score. A tank is a passive vessel, so it leads with what feeds it and what it feeds, and its sensors. Nothing is hidden by hand — a block is absent because the type does not declare it.

How the profile works. Blocks are declared per type and rendered in the type's order: rotating machine = attributes · health · linked · sensors; passive vessel = linked · sensors, with no health score at all because nothing rotates and no attribute set is worth the room. Issues, tasks and history are constant — every asset accumulates a record. Maintenance is conditional: a tank with a desludging programme gets the tab, one with condition-based inspection only does not. Try the jump buttons above to compare a blower, a tank, an instrument and a screen in the same frame.
